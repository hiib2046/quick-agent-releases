# Quick Agent 다운로드

단축키로 여는 작은 ChatGPT 대화창입니다. Windows x64용 설치 파일과 변경 내용을 제공합니다.

[최신 설치 파일 다운로드](https://github.com/hiib2046/quick-agent-releases/releases/latest)

0.2.17부터 앱 시작과 실행 중 1시간마다 새 버전을 확인하고 자동으로 다운로드합니다. 입력창 오른쪽의 원형 표시가 파란 다운로드 아이콘으로 바뀌면 클릭해 설치 화면 없이 업데이트하고 다시 실행합니다. 설정과 기록, 입력 초안을 유지하도록 구성합니다. 0.2.16 이전 버전은 최신 설치 파일을 한 번 수동으로 설치해야 합니다.

현재는 미서명 테스트 빌드입니다. 각 사용자가 자신의 ChatGPT 계정으로 로그인합니다. 이 저장소에는 소스 코드나 개인 로그인 프로필, 대화 기록, 개발자의 인증 토큰을 넣지 않습니다.

설치 파일의 SHA-256은 각 릴리즈의 `SHA256SUMS.txt`로 확인할 수 있습니다. `latest.yml`과 `.exe.blockmap`은 앱의 업데이트를 위한 배포 파일입니다.
