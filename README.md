# Quick Agent 다운로드

단축키로 여는 작은 ChatGPT 대화창입니다. Windows x64용 설치 파일과 변경 내용을 제공합니다.

[최신 설치 파일 다운로드](https://github.com/hiib2046/quick-agent-releases/releases/latest)

0.2.17부터 앱 시작과 실행 중 1시간마다 새 버전을 확인하고 자동으로 다운로드합니다. 입력창 오른쪽의 원형 표시가 파란 다운로드 아이콘으로 바뀌면 클릭해 설치 화면 없이 업데이트하고 다시 실행합니다. 설정과 기록, 입력 초안을 유지하도록 구성합니다. 0.2.16 이전 버전은 최신 설치 파일을 한 번 수동으로 설치해야 합니다.

0.2.18부터 버전 확인 요청은 30초로 제한합니다. 다운로드는 60초 동안 수신이 없거나 전체 30분을 넘으면 실제 요청을 중단합니다. 실패한 경우 수동 확인이나 다음 정기 확인으로 다시 시도합니다.

현재는 미서명 테스트 빌드입니다. 각 사용자가 자신의 ChatGPT 계정으로 로그인합니다. 이 저장소에는 소스 코드나 개인 로그인 프로필, 대화 기록, 개발자의 인증 토큰을 넣지 않습니다.

설치 파일의 SHA-256은 각 릴리즈의 `SHA256SUMS.txt`로 확인할 수 있습니다. `latest.yml`은 앱의 업데이트 확인에 필요합니다. `.exe.blockmap`은 차등 다운로드용 보조 파일이며 현재 앱은 전체 다운로드를 사용합니다.

## 릴리즈 파일

- 처음 설치할 때는 `Quick-Agent-VERSION-setup-unsigned.exe`만 다운로드합니다.
- `latest.yml`은 앱이 업데이트 버전과 설치 파일의 무결성을 확인할 때 사용합니다.
- `SHA256SUMS.txt`는 사용자가 파일을 직접 검증하는 데 씁니다.
- `.exe.blockmap`은 차등 다운로드용 보조 파일입니다. 현재 앱은 전체 다운로드를 사용합니다.
- GitHub가 자동 제공하는 Source code ZIP과 TAR는 이 배포 저장소의 README만 포함합니다. 앱 소스는 포함하지 않습니다.
